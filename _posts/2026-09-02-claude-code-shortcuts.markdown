# 40 Claude Code Shortcuts

Working efficiently in the terminal with AI can save hours every single day. Here is a comprehensive cheat sheet featuring **40 essential Claude Code shortcuts** categorized by session control, code quality, parallelism, tuning, project setup, and utilities.

Original graphic by MJ Jaindl. Check out the [original LinkedIn post](https://lnkd.in/p/eatYEmKQ) for the source and further insights.

## Cheat Sheet Tables

### 01. Control the Session

| Shortcut | Description |
| :--- | :--- |
| `/clear` | Fresh start |
| `/compact` | Shrink context, keep the facts |
| `/context` | See what's eating your tokens |
| `/rewind` | Roll back code and chat |
| `/resume` | Reopen any old session |
| `/branch` | Split off a new direction |
| `/fork` | Duplicate it, explore both |

### 02. Ship Better Code

| Shortcut | Description |
| :--- | :--- |
| `/plan` | Plan before any edits |
| `/diff` | See uncommitted changes |
| `/code-review` | Hunt bugs in the diff |
| `/security-review` | Find security holes |
| `/review` | Review a GitHub PR |

### 03. Work in Parallel

| Shortcut | Description |
| :--- | :--- |
| `/tasks` | List everything running |
| `/background` | Detach, keeps working |
| `/batch` | Fan a job across agents |
| `/subtask` | Side job to a subagent |
| `/btw` | Quick side question |
| `/teleport` | Web session to terminal |
| `/remote-control` | Continue from your phone |

### 04. Tune Claude

| Shortcut | Description |
| :--- | :--- |
| `/model` | Switch models mid-session |
| `/effort` | Dial reasoning up or down |
| `/config` | Every setting in one menu |
| `/theme` | Change the colors |
| `/color` | Tint the prompt bar |
| `/keybindings` | Rebind any key |
| `/voice` | Talk instead of type |

### 05. Set Up Your Project

| Shortcut | Description |
| :--- | :--- |
| `/init` | Generate your `CLAUDE.md` |
| `/memory` | Edit what Claude remembers |
| `/mcp` | Connect outside tools |
| `/permissions` | What runs without asking |
| `/add-dir` | Open up another folder |
| `/cd` | Change directories |
| `/terminal-setup` | Fix Shift+Enter |

### 06. Utilities

| Shortcut | Description |
| :--- | :--- |
| `/usage` | Tokens and cost so far |
| `/status` | Model, mode, and directory |
| `/doctor` | Diagnose a broken install |
| `/debug` | Verbose logs, weird moments |
| `/copy` | Copy the last response |
| `/export` | Save the chat to a file |
| `/feedback` | Report a bug with context |
